INTERPRETATION
----------------------------------------------------------------------
The reference set consists exclusively of records with manipulation_type = none.
Observed attribute combinations in this reference set are treated as empirically observed normal credential patterns.
A manipulated record is classified as novel for a relationship when its attribute combination does not occur in the normal reference set.

Important limitation:
Absence from the reference set does not prove that a credential combination is academically invalid.
Novelty should therefore be interpreted as an empirical inconsistency signal rather than a formal academic validity judgment.
